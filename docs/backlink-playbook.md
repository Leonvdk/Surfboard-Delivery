# Backlink playbook — Surf Rental Aljezur

Goal: ~25 relevant local + niche links over ~3 months. Relevance beats volume.
Never buy links or use link farms. Half of these also drive real bookings.

Why now: GA shows Referral traffic is near-zero and Direct is ~74%. Backlinks +
UTM tagging are what build a real, attributable channel mix.

## UTM conventions

Append to EXTERNAL inbound links only (never links between your own pages).
Lowercase, consistent spelling.

- `utm_source` = platform/partner (`instagram`, `google`, `casa_arrifana`, `newsletter`)
- `utm_medium` = `organic_social` | `qr` | `referral` | `email`
- `utm_campaign` = the specific push (`bio`, `weekend_surf_check`, `partners`)

Ready links:
- IG bio: `https://surfrental-aljezur.com/?utm_source=instagram&utm_medium=organic_social&utm_campaign=bio`
- Weekend Surf Check: `…/?utm_source=instagram&utm_medium=organic_social&utm_campaign=weekend_surf_check`
- Sticker/QR: `…/?utm_source=sticker&utm_medium=qr&utm_campaign=amoreira`
- Partner: `…/?utm_source=[partner]&utm_medium=referral&utm_campaign=partners`

Build fast with Google's Campaign URL Builder (ga-dev-tools.google/campaign-url-builder).

## Measure it (monthly)

- GA4 → Reports → Acquisition → Traffic acquisition → dimension **Session source/medium** or **Session campaign**.
- Google Search Console → Links report (who links to you).
- Free Ahrefs Backlink Checker for a periodic spot-check.
- Per partner: clicks in GA (UTM) + bookings in Stripe (code redemptions).

## Cadence

- Week 1: citations (Tier 1) + link Search Console.
- Week 2: partner list + codes/links + send template A.
- Ongoing: 1–2 HARO answers/week; UTM-tag every link you post; revisit monthly.
